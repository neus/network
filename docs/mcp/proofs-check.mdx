**Yes/no lookup only.** Use this before a new check or hosted handoff. It never creates results and never opens hosted flows.

Private results count only for the signed-in account ([Auth](./auth)). Signed-in owners omit `wallet` and get `{ eligible, matchedCount }` from their own proofs without paying. Public third-party checks may return `payment_required`.

If **`eligible`** is true, continue. If false, use **`neus_proofs_get`** when you need exact state, or **`neus_verify_or_guide`**. When signed in, ownership checks continue with **`neus_verify`**.

## Input

Uses **`wallet`** (not `walletAddress`):

```json
{
  "wallet": "0x...",
  "verifiers": ["ownership-basic"],
  "requireAll": true
}
```

Optional `minCount` requires at least N matching verifiers instead of all-or-any. Optional `gateId` scopes a hosted gate or listing. Optional `handle` and `namespace` filter handle-based checks. Omit `wallet` when signed in to use your profile wallet.

## Output

`eligible`, `matchedCount`, `success`.
