Connect assistants to identity, authority, saved results, and encrypted secrets.

**Hosted endpoint:** `https://mcp.neus.network/mcp`

To use a profile agent in a project, choose **Connect in** on its agent card, then run the copied `neus mount` command in that project.

<Tabs sync={false}>
  <Tab title="Quick start">

```bash
npx -y -p @neus/sdk neus setup
npx -y -p @neus/sdk neus doctor --live
```

Installs the trust skill and configures hosted MCP for Cursor, Claude Code, Codex, and VS Code in one command. In Cursor, installing the **neus-mcp** marketplace plugin is the fastest path — it auto-registers NEUS MCP and runs OAuth in one click (the CLI then defers to the plugin).

Ask your assistant: **"Before I take a sensitive action, use NEUS. Reuse what I already have."** It looks up identity, authority, and saved results first, then summarizes as Passed, Action needed, or Blocked.

```bash
npx -y -p @neus/sdk neus setup --client cursor
npx -y -p @neus/sdk neus setup --client codex
npx -y -p @neus/sdk neus setup --client vscode
npx -y -p @neus/sdk neus setup --client claude
```

  <Tab title="Cursor">
    <Icon icon="/images/brandLogos/cursor.svg" size={18} /> **Cursor**

**Option 1 — Marketplace (recommended, one-click OAuth):**

```text
Cursor → Settings → Cursor Plugins → Add marketplace
Marketplace URL: https://github.com/neus/network
Install: neus-mcp
```

Clicking **Install** auto-registers NEUS MCP and starts OAuth. After install, click **Connect** to sign in. No CLI needed.

**Option 2 — CLI:**

```bash
npx -y -p @neus/sdk neus setup --client cursor
```

Writes the user-level registration at `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "neus": {
      "url": "https://mcp.neus.network/mcp"
    }
  }
}
```

When both are present, the CLI detects the plugin and skips writing a duplicate entry — use one or the other, not both.

Expected public tool list: **13**. Profile loads via `neus_context` when signed in.

## Other MCP hosts

Add remote MCP URL **`https://mcp.neus.network/mcp`** in the host settings, or the JSON below for file-based config.

| Host | Config file |
|------|-------------|
| Claude Desktop | `~/.claude.json` → `mcpServers` |
| Cline | `cline_mcp_settings.json` in Cline settings |
| Windsurf | `~/.codeium/windsurf/mcp_config.json` |
| Gemini CLI | `~/.gemini/settings.json` or `gemini mcp add --transport http neus https://mcp.neus.network/mcp` |
| ChatGPT | Remote MCP URL in client settings |

For servers and CI, use Profile access keys in bearer headers: [Auth](./auth).

```json
{
  "mcpServers": {
    "neus": {
      "type": "http",
      "url": "https://mcp.neus.network/mcp"
    }
  }
}
```

## Servers and CI

```bash
npx -y -p @neus/sdk neus setup --access-key <npk_...>
```

Keys: [Profile -> Account](https://neus.network/profile?tab=account). Never paste keys into chat.

<Warning>
  Use **`https://mcp.neus.network/mcp`** for trust receipts and agent tools. The docs site also offers a **search-only** endpoint at `https://docs.neus.network/mcp` - it cannot verify identity or create receipts.
</Warning>
