Connect NEUS once. Your assistant can then reuse your current checks and permissions before it spends, publishes, uses secrets, or calls a sensitive tool.

Keep your model and agent framework. NEUS adds the decision before action.

## Connect

```bash
npx -y -p @neus/sdk neus setup
```

Click **Connect** in your assistant and finish browser sign-in. No wallet or access key is required.

Then ask:

> Before you take a sensitive action, use NEUS. Reuse what I already have.

NEUS answers **Passed**, **Action needed**, or **Blocked** before the action runs.

## Share proof. Not private data.

One endpoint. One sign-in. Trust that travels.

What carries between assistants:

- Your profile and current permissions
- Completed checks that are still valid
- A portable proof another connected app can confirm

NEUS returns the check result and proof, not the private data used to complete the check.

The same hosted endpoint works with Cursor, Codex, Claude, VS Code, and other remote MCP clients:

`https://mcp.neus.network/mcp`
