Add a check before your assistant spends, publishes, uses secrets, or calls a sensitive tool. NEUS reuses a current proof when it can and asks only for the missing step.

**Hosted endpoint:** `https://mcp.neus.network/mcp`

## 1. Run setup

```bash
npx -y -p @neus/sdk neus setup
```

This adds the NEUS connection and the instructions your assistant needs to use it.

## 2. Connect your account

Click **Connect** in your assistant and finish browser sign-in. You do not need a wallet or access key.

If your host cannot start sign-in, run `npx -y -p @neus/sdk neus auth`.

## 3. Protect an action

Ask:

> Before you take a sensitive action, use NEUS. Reuse what I already have.

NEUS answers **Passed**, **Action needed**, or **Blocked** before the action runs.

## Let your assistant run setup

```text
# NEUS connect in one prompt

You are connecting this client to NEUS so it can reuse completed checks
and confirm permission before sensitive actions.

1. Run: npx -y -p @neus/sdk neus setup
2. Tell me to click Connect in this client if sign-in is still needed.
   Default sign-in is browser OAuth. No wallet. No access key.
3. After connect, reuse my existing proofs before asking me to verify
   again. Before any sensitive action (spend, publish, secrets, agent
   tool call), load context once, then check proofs. Summarize as
   NEUS Verify: Passed, Action needed, or Blocked.

Canonical endpoint: https://mcp.neus.network/mcp
Docs: https://docs.neus.network/mcp/setup
```

## Advanced: any MCP client

Add one remote server. Your client discovers OAuth from the hosted endpoint.

```json
{
  "mcpServers": {
    "neus": {
      "url": "https://mcp.neus.network/mcp"
    }
  }
}
```

If your client requires the spec `type` field:

```json
{
  "mcpServers": {
    "neus": {
      "type": "http",
      "url": "https://mcp.neus.network/mcp"
    }
  }
}
```

## Advanced: connect a Trusted Agent to a project

After creating a Trusted Agent on your profile, load its current identity and permissions:

```bash
npx -y -p @neus/sdk neus mount <agentId> --apply <host>
```

The command writes `.neus/mount.json` and the selected host adapter. See [Connect agent context](../agents/runtime-mount).

## Advanced: access keys

Use OAuth for interactive clients. Use a [profile access key](https://neus.network/profile?tab=account) only when browser OAuth is unavailable, such as a server or CI job.

```bash
export NEUS_ACCESS_KEY=npk_...
npx -y -p @neus/sdk neus setup
```

Treat the key like a password. Never paste it into chat or commit it to a repository.

## Disconnect

```bash
neus disconnect --access-key <token>
```

## Troubleshooting

- **No tools appear:** restart the MCP client after setup.
- **Authentication required:** click **Connect**, or run `neus auth`.
- **Confirm the connection:** `neus doctor --live`.
- **Agent permission missing:** create or refresh the agent permission on NEUS, then run `neus mount` again.
- **Search-only endpoint:** use `https://mcp.neus.network/mcp`. `https://docs.neus.network/mcp` only searches documentation.
