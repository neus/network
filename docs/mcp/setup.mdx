**Hosted endpoint:** `https://mcp.neus.network/mcp`

## 1. Register NEUS

```bash
npx -y -p @neus/sdk neus setup
```

This installs the public workflow skill and configures supported MCP clients. It does not open a browser or sign you in.

To configure one client:

```bash
npx -y -p @neus/sdk neus setup --client cursor
npx -y -p @neus/sdk neus setup --client codex
npx -y -p @neus/sdk neus setup --client vscode
npx -y -p @neus/sdk neus setup --client claude
```

## 2. Sign in

Click **Connect** in your MCP client, or run:

```bash
npx -y -p @neus/sdk neus auth
```

Codex manages its own OAuth session:

```bash
npx -y -p @neus/sdk neus auth --client codex
```

## 3. Check the connection

```bash
npx -y -p @neus/sdk neus doctor --live
```

A healthy result confirms that the endpoint is registered, authentication works, and the public MCP tools are available.

## Connect an agent to a project

After creating a Trusted Agent on your profile, load its current identity and permissions:

```bash
npx -y -p @neus/sdk neus mount <agentId> --apply cursor
```

Replace `cursor` with `claude` or `codex` for those hosts. The command writes `.neus/mount.json` and the selected host adapter. See [Connect agent context](../agents/runtime-mount).

## Access keys

Use OAuth for interactive clients. Use a [profile access key](https://neus.network/profile?tab=account) only when browser OAuth is unavailable, such as a server or CI job.

```bash
export NEUS_ACCESS_KEY=npk_...
npx -y -p @neus/sdk neus setup
npx -y -p @neus/sdk neus doctor --live
```

Treat the key like a password. Never paste it into chat or commit it to a repository.

## Disconnect

```bash
neus disconnect --access-key <token>
```

## Troubleshooting

- **No tools appear:** restart the MCP client after setup, then run `neus doctor --live`.
- **Authentication required:** click **Connect** or run `neus auth`.
- **Agent permission missing:** create or refresh the agent permission on NEUS, then run `neus mount` again.
- **Search-only endpoint:** use `https://mcp.neus.network/mcp`. `https://docs.neus.network/mcp` only searches documentation.
