One access link owns the checks, price, and sign-in. Your app never runs the check logic. Visitors need no NEUS account and no API key.

## Build it

<Steps>
  <Step title="Publish a listing">
    Sign in at [neus.network](https://neus.network), open your profile → **Listings**, choose the checks visitors must pass, set pricing (you pay by default, or charge visitors), and **Publish**. Copy your `gateId`. Visitors only ever need that.
  </Step>
  <Step title="Gate content with VerifyGate">
    ```jsx
    import { VerifyGate } from '@neus/sdk/widgets';

    <VerifyGate gateId="gate_your-app-name">
      <ProtectedContent />
    </VerifyGate>;
    ```
    `VerifyGate` looks for an existing proof, opens hosted sign-in on NEUS only when a new one is needed, then renders your content. Wallet, passkey, and OAuth all happen on NEUS, not inside your app.
  </Step>
  <Step title="Show status with ProofBadge">
    ```jsx
    import { ProofBadge } from '@neus/sdk/widgets';

    <ProofBadge qHash={proof.qHash} />;
    ```
    Optional: pass `showChains` when you want on-chain status in the badge.
  </Step>
  <Step title="Confirm on your server">
    Before you grant access or pay out, confirm the visitor still satisfies the gate. Pass the **account address** from the NEUS sign-in flow or the saved result. Every NEUS account has one (passkey and OAuth included). No separate crypto wallet required:
    ```js
    import { NeusClient } from '@neus/sdk';

    const client = new NeusClient();
    const result = await client.gateCheck({
      gateId: 'gate_your-app-name',
      address: user.accountAddress, // from Hosted Verify / stored proof subject
    });

    if (!result.data?.gate?.allRequiredSatisfied) {
      // send the user back to VerifyGate or NEUS sign-in
    }
    ```
  </Step>
</Steps>

The visitor’s proof is theirs. If they return or visit another gate that needs the same checks, they can reuse it.

## Not using React? Send users to NEUS for sign-in

```js
import { getHostedCheckoutUrl } from '@neus/sdk';

window.location.assign(
  getHostedCheckoutUrl({
    gateId: 'gate_your-app-name',
    returnUrl: 'https://myapp.com/auth/callback',
  }),
);
```

Read the **proof ID** (`qHash`) from the callback URL or popup message, then store it. Details: [Hosted sign-in](./cookbook/auth-hosted-verify).
